## Project goal

Build an end-to-end MLOps pipeline that predicts `litres_per_day` for village milk collection centres. The project covers data quality checks and cleaning, model training and MLflow tracking, a FastAPI prediction service, Docker, CI, Kubernetes manifests, drift monitoring, retraining, and holdout predictions.

## Repository structure

The code and reports will be added under `src/`, `app/`, `tests/`, `reports/`, and `predictions/` as the group completes the project stages. Dataset files are tracked with DVC.
